## What is Butterfly?

Butterfly is a lightweight, open protocol for connecting independent AI conversations.

It enables two separate conversations to exchange information through a human intermediary, while preserving their independence and making the exchange explicit and traceable.

The initial implementation requires no API integration, shared infrastructure, or direct access between AI systems. A human participant carries messages between conversations.

## Why Butterfly?

AI conversations are usually isolated. Useful knowledge, ideas, and reasoning developed in one conversation cannot easily be transferred to another while preserving their context and origin.

Butterfly explores a simple possibility: independent conversations can collaborate through a small, structured communication protocol.

The protocol is designed around:

- **Autonomy:** Each participant remains independent.
- **Human control:** The human intermediary decides what crosses the boundary.
- **Provenance:** Messages retain information about their origin.
- **Explicit permissions:** Information is exchanged within defined boundaries.
- **Minimal infrastructure:** The initial protocol works through copy and paste.

## Protocol

The initial experimental vocabulary includes:

- `SYNC`: Exchange selected information between participants.
- `CHECK`: Verify or clarify an exchange.
- `IDLE`: Indicate that no further exchange is currently required.

The detailed message format and state transitions are under development.

## Current status

**Early experimental development.**

The repository currently establishes the project and its direction. The protocol specification, examples, and validation tests will be added incrementally.

## Open questions

Participant identity, conversation identity, permission boundaries, message provenance, and verification semantics require further specification.

These questions will be tracked explicitly as the protocol evolves.
